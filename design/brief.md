# Бриф: редизайн главной consultantlm.com — 10 концептов

## Контекст
CONSULTANT Legal Marketplace — юридический маркетплейс (рынок США). Заказчик утвердил направление:
**светлая основа + дозированные тёмные секции**, референс — apple.com: пространство, строгость,
никакого визуального шума, читаемость превыше всего, современно и легко.

## Жёсткие ограничения (нарушать нельзя)
1. **Шрифт** только Avenir Next Cyr (400/500/600/700) — подключён в `tokens.css`. Никаких других шрифтов. Bicubik НЕ использовать (заказчик отказался от капс-заголовков).
2. **Заголовки без КАПСА** — обычный регистр (Sentence case), читаемые, сплошной цвет (никаких прозрачных контуров и градиентных заливок текста).
3. **Цвета** только из палитры бренда (см. tokens.css): синий #1397D6, чёрный/#1B1B1B, белый, #F8F9FC, серые. Один синий на все кнопки — #1397D6, hover #0F7FB5.
4. **Радиус скруглений ≤ 3px** — везде (кнопки, карточки, поля, фото). Используй `var(--radius)`.
5. **Без фоновых изображений** в секциях и карточках. Фото только как контентные `<img>` в отведённых рамках (аватары консультантов, превью новостей, иконки шагов). Фоны секций — только сплошные цвета из палитры.
6. **Контент 1:1** из `content/home.json` — все секции, все тексты, все ссылки. Ничего не выкидывать, не переписывать (исправленные опечатки в JSON уже учтены). Порядок секций сохранить: hero → How We Work → offer (3 карточки: Legal Services / Documents / Consultations) → Top 10 PRO consultants → Reviews → Quiz → About us + новости → Trust/карта/контакты → футер.
7. **Логотип**: на светлой шапке `assets/img/logo_dark.svg`, на тёмных секциях/футере `assets/img/logo_en.svg`. Не искажать, не перекрашивать.

## Обязательные элементы каждого варианта
- **Шапка**: светлая (белая/полупрозрачная с blur), sticky, с рамкой-разделителем снизу. Полное меню из 6 пунктов (Services, Consultants, Documents, Blog, Vacancies, About us) видно на десктопе + кнопка Login + поиск (видимое поле или иконка, раскрывающаяся в поле) + переключатель EN. На мобильном — бургер с полноэкранным/выпадающим меню (реализовать работающим на чистом CSS/JS). Активный пункт подчёркивается.
- **Hero**: чистый, без фото-подложек. H1 «A Lawyer is always there for you!» тёмным по светлому (или белым по тёмному, если вариант делает тёмный hero-band). Форма: селект кода страны (6 опций из JSON) + телефон + кнопка «Get help». Подпись-ошибку «Phone number is required» показывать ТОЛЬКО после сабмита пустого поля (реализовать в JS).
- **Тёмные секции — дозировано**: 1–2 тёмные секции на страницу (например Top 10 консультантов и/или футер). Текст на тёмном — белый/72% белого, контраст ≥ 4.5:1.
- **Карточки консультантов**: без фото-подложек — аватар как контентное фото в рамке карточки, бейдж PREMIUM, рейтинг со звездой, Top N, имя, роль, гео. Ссылка «All consultants».
- **Отзывы**: слайдер или карусель/грид с управлением (стрелки + возможность свайпа), карточки с чёткими границами на контрастном фоне. Показывать удобно, 32 отзыва из JSON (можно лениво/страницами).
- **Quiz**: пошаговый (по одному вопросу за раз, прогресс-бар, Yes/No), в конце шаг с телефоном и кнопкой «Get a calculation». Никаких стен радиокнопок.
- **About**: текст достижений + лента новостей (11 карточек с датами; превью-картинки хотлинк с сайта, у последней новости img=null — карточка без изображения должна выглядеть аккуратно).
- **Trust/контакты**: текст о проверке специалистов, блок Portal Administration (адрес-ссылка, email, телефон, кнопка Request a Call), карта Google (iframe) как контентный блок в рамке с радиусом 3px — не фоном.
- **Футер**: тёмный (#1B1B1B) или светлый с верхней рамкой — по концепту. Юр. ссылки, навигация, промо приложения (текст + бейджи App Store/Google Play), соцсети, полный дисклеймер мелким текстом, «Popular services» (12 ссылок) компактной колонкой или аккордеоном.
- **Плавающие элементы**: одна аккуратная кнопка чата в правом нижнем углу (без автопопапа с текстом — просто кнопка с пульс-точкой). Cookie-баннер компактный внизу.

## Анимации (лёгкие, у всего что уместно)
- Scroll-reveal через `[data-reveal]` + IntersectionObserver (паттерн в tokens.css), каскадные задержки для карточек (стагер 60–90 мс).
- Hover: кнопки (затемнение + лёгкий подъём 1–2px), карточки (тень/рамка + подъём), ссылки меню (подчёркивание слева-направо).
- Слайдеры с плавным transition. Числа-счётчики можно анимировать при появлении.
- Всё уважает `prefers-reduced-motion` (уже в tokens.css).
- Никаких паралаксов на фото, никаких бесконечных анимаций, кроме микропульса на кнопке чата.

## Адаптив
Обязателен: 1280+ / 768 / 375. Мобильное меню работает. Грид-секции складываются в колонку. Горизонтальные слайдеры остаются свайпабельными.

## Технически
- Один самодостаточный файл `variants/vNN.html` (NN = номер варианта) + подключение `../tokens.css` (путь относительный: `<link rel="stylesheet" href="../tokens.css">`). Свои стили и JS — инлайн в файле.
- Изображения контента хотлинкятся с consultantlm.com (URL в JSON). Аватары/иконки снабжай `alt`.
- Семантика: header/nav/main/section/footer, единственный h1. JS — ванильный, без библиотек.
- В начале файла HTML-комментарий: название концепта и 2–3 предложения его идеи по-русски.

## Чем варианты должны отличаться
Каждый вариант — своя композиция hero, свой ритм секций (где тёмные вставки), свой стиль карточек и меню в рамках общих правил. Не менять контент и палитру — менять компоновку, пропорции, сетки, характер анимаций.
