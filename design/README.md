# Consultant Legal Marketplace — концепты редизайна

Прототипы редизайна главной страницы [consultantlm.com](https://consultantlm.com/).
Онлайн: **https://markichyt.github.io/advocatplus-bottom-nav/design/**

## Что здесь

| Путь | Что это |
|------|---------|
| `index.html` | Галерея всех концептов с переключателем радиуса скруглений |
| `variants/v01…v10.html` | 10 концептов, строгая геометрия — радиус 3px |
| `variants-rounded/r01…r10.html` | Те же 10 концептов, мягкая геометрия — радиус 9–12px |
| `tokens.css` | Дизайн-токены: шрифты, палитра, типографика, отступы, анимации |
| `content/home.json` | Весь контент главной 1:1 (тексты, ссылки, данные карточек) |
| `brief.md` | Дизайн-бриф: правила, которым следуют все варианты |
| `assets/` | Шрифты Avenir Next Cyr, логотипы, фото консультантов, новости, иконки |

## Правила дизайна

- Светлая основа с дозированными тёмными секциями
- Шрифт Avenir Next Cyr (400/500/600/700), фирменный синий `#1397D6`
- Заголовки без капса, сплошным цветом — никаких прозрачных контуров и градиентного текста
- **Без фоновых изображений** в блоках: фото только контентные, в своих рамках
- Контент 1:1 с текущим сайтом — верстка «переодевается» без потери данных
- Лёгкие анимации: scroll-reveal, hover, слайдеры; учитывается `prefers-reduced-motion`
- Навигация: все 6 разделов в шапке + поиск + Login + EN, рабочий мобильный бургер

## Шкала скруглений

| Набор | Крупные блоки | Кнопки и поля | Бейджи |
|-------|---------------|---------------|--------|
| Строгий (`variants/`) | 3px | 3px | 3px |
| Мягкий (`variants-rounded/`) | 12px | 8px | 6px |

## Локальный запуск

```bash
python3 -m http.server 8407 --directory redesign
```

Затем откройте http://localhost:8407/
